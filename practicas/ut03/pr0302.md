# PR0302. Transformación a capa plata en Parquet

## 1. Contexto

En la práctica anterior (`PR0301`) construiste la **Capa Bronce** del Data Lake de la Secretaría de Estado de Turismo en Amazon S3, almacenando en crudo los catálogos de MITECO y AEMET junto con las predicciones meteorológicas diarias en JSON.

Sin embargo, los datos en Capa Bronce todavía no están listos para que los analistas o los modelos de Machine Learning trabajen con ellos de forma eficiente:

- Existen **problemas de calidad y formato**: codificaciones distintas (`UTF-8` vs `ISO-8859-1`), valores vacíos representados como espacios en blanco (`" "`), códigos INE sin ceros a la izquierda (ej. `3018` en lugar de `03018`) y campos booleanos escritos como texto (`"Sí"` / `"No"`).
- Las dos fuentes maestras **no comparten identificador de playa** (`Identifica` en MITECO frente a `ID_PLAYA` en AEMET), por lo que no se pueden cruzar directamente.
- Las predicciones diarias están dispersas en **múltiples ficheros JSON pequeños y anidados**, lentos de leer y difíciles de consultar en formato tabular.

Tu misión en esta práctica es construir el pipeline de transformación **Bronce a Plata** en Python utilizando `boto3`, `pandas` y `pyarrow`, generando tablas limpias, unificadas y almacenadas en **Apache Parquet**.



## 2. Objetivos

Los objetivos de esta práctica son:

- **Arquitectura de Data Lake (Capa Plata):** diseñar tablas analíticas limpias, tipadas y particionadas en formato columnar **Apache Parquet** sobre Amazon S3.
- **Limpieza y estandarización de datos:** gestionar valores nulos ocultos (`" "`), normalizar nombres de columnas (`snake_case`), convertir tipos de datos (`bool`, `float`, `string` con ceros a la izquierda) y eliminar duplicados.
- **Resolución de entidades:** cruzar dos catálogos heterogéneos sin clave primaria común mediante normalización de texto y coincidencia difusa  restringida por código INE de municipio.
- **Aplanado de datos semiestructurados:** transformar archivos JSON anidados de la API de AEMET en un esquema tabular consolidado por partición diaria.
- **Optimización de almacenamiento:** comprobar el ahorro de espacio y las ventajas de lectura columnar (*Projection Pushdown*) de Parquet frente a CSV y JSON.


## 3. Diseño de la Capa Plata en S3

Trabajarás sobre el mismo bucket creado en `PR0301` (`datalake-turismo-bronce-<tus-iniciales>`), añadiendo un nuevo prefijo raíz `plata/` con dos conjuntos de datos en formato **Parquet** (compresión `snappy`):

### 3. Normalización de texto y *Fuzzy Matching* con librería estándar

No necesitas instalar librerías externas; Python incluye `unicodedata` y `difflib`:

```python
import re
import unicodedata
from difflib import SequenceMatcher

def normalizar_nombre(texto: str) -> str:
    if not isinstance(texto, str):
        return ""
    # Quitar tildes y pasar a minúsculas
    texto = unicodedata.normalize("NFKD", texto).encode("ascii", "ignore").decode("utf-8").lower()
    # Quitar prefijos habituales de playas
    texto = re.sub(r"^(playa de la |playa del |playa de |playa |platja de |cala )", "", texto)
    # Dejar solo letras, números y un espacio simple
    texto = re.sub(r"[^a-z0-9\s]", " ", texto)
    return " ".join(texto.split())

def similitud(a: str, b: str) -> float:
    return SequenceMatcher(None, normalizar_nombre(a), normalizar_nombre(b)).ratio()

# Ejemplo de uso
score = similitud("Playa de El Postiguet", "El Postiguet")  # -> 1.0

```

### 4. Aplanado del JSON de AEMET

El JSON de AEMET devuelve una lista con un único elemento que contiene la lista `prediccion["dia"]`:

```python
def aplanar_prediccion(datos_json: list, fecha_ingesta: str) -> list[dict]:
    filas = []
    if not datos_json:
        return filas
    
    playa = datos_json[0]
    id_playa = str(playa.get("id", "")).zfill(7)
    dias = playa.get("prediccion", {}).get("dia", [])

    for dia in dias:
        fecha_raw = str(dia.get("fecha", ""))  # Ej: "20261124"
        fecha_fmt = f"{fecha_raw[:4]}-{fecha_raw[4:6]}-{fecha_raw[6:8]}" if len(fecha_raw) == 8 else None

        filas.append({
            "id_playa": id_playa,
            "fecha_prediccion": fecha_fmt,
            "estado_cielo": dia.get("estadoCielo", {}).get("descripcion1"),
            "viento": dia.get("viento", {}).get("descripcion1"),
            "oleaje": dia.get("oleaje", {}).get("descripcion1"),
            "temp_maxima": dia.get("tMaxima", {}).get("valor1"),
            "temp_agua": dia.get("tAgua", {}).get("valor1"),
            "uv_max": dia.get("uvMax", {}).get("valor1"),
            "fecha_ingesta": fecha_ingesta
        })
    return filas

```

### 5. Guardar un DataFrame en Parquet directamente en S3 desde memoria

```python
import io
from datetime import datetime, timezone

def subir_parquet_a_s3(df: pd.DataFrame, bucket: str, key: str, s3_client) -> None:
    buffer = io.BytesIO()
    df.to_parquet(buffer, engine="pyarrow", compression="snappy", index=False)
    buffer.seek(0)  # Rebobinar el buffer al principio antes de subir

    timestamp_iso = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
    s3_client.put_object(
        Bucket=bucket,
        Key=key,
        Body=buffer.getvalue(),
        Metadata={"layer": "silver", "processed_timestamp": timestamp_iso},
    )

```
